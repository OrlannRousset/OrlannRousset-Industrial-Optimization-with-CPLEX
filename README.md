# Recherche opérationnelle — Modélisation et optimisation avec CPLEX OPL

Travaux réalisés dans le cadre d'un enseignement de recherche opérationnelle à l'UTT.

## Contenu

### Problème 1 — MRP / Make-or-Buy
Modèle d'optimisation du choix entre fabrication/assemblage interne et achat de produits
et composants afin de satisfaire la demande au coût minimum.

### Problème 2 — Écoulement optimal de stocks
Optimisation de l'affectation de lots de médicaments dans le temps afin de maximiser
leur efficacité moyenne, avec comparaison préalable de règles FIFO et LIFO.

### Problème 3 — Planification dynamique de production
Planification multi-périodes avec coûts de variation de production et de stockage.
Une seconde version ajoute une approche robuste face à un scénario de perturbation
de la production.

### Problème 4 — Production / sous-traitance
Le rapport contient la formulation et les résultats, mais pas le code `.mod` / `.dat`
d'origine. Le dossier est donc laissé sans reconstruction automatique.

## Outils
- IBM ILOG CPLEX Optimization Studio
- OPL
- Programmation linéaire / linéaire mixte
- Optimisation robuste
